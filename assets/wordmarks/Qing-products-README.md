# QingCloud / QingEdge Wordmark

- `QingCloud-wordmark-blue.svg`：QingCloud 青萍蓝字标。
- `QingEdge-wordmark-blue.svg`：QingEdge 青萍蓝字标。
- 同名 `-preview.png`：白底审阅图；正式 SVG 为透明背景。

两个字标共用 Qingping 正式 Logo 中已确认的 “Qing” 矢量轮廓与直线锐角 Q 尾巴。Cloud 和 Edge 使用 Nunito Sans 700 的矢量轮廓，按原字标的字高和基线调整；文件不依赖安装字体。色值为青萍蓝 `#073B53`。

后缀字形所用 Nunito Sans 的 OFL 许可见 `NunitoSans-OFL.txt`。
