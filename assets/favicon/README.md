# Qingping favicon

沿用已选 Logo 的白色 Q 字形与青蓝色渐变背景，采用单字母以提高小尺寸辨识度。

将此目录内的图片复制到网站根目录，并在 HTML 的 `<head>` 内加入：

```html
<link rel="icon" href="/favicon.ico" sizes="16x16 32x32 48x48">
<link rel="icon" type="image/png" sizes="32x32" href="/favicon-32x32.png">
<link rel="apple-touch-icon" sizes="180x180" href="/apple-touch-icon.png">
```

另附 192 和 512 像素 PNG，供网站应用图标使用。

设计使用内置图像生成工具完成；尺寸转换与 ICO 封装在本地执行。
设计提示词：沿用原 Qingping Logo 的青蓝渐变及几何圆形白色 Q，将完整文字简化为居中的单字母 Q，放大并保持留白，适合 16 像素显示，扁平、无阴影。
